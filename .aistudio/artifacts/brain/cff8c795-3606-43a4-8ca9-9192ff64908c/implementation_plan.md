# خطة العمل: تطبيق قائمة التفقد الأكاديمية ونظام التذكير الدوري (بدون AI)

خطة تنفيذ شاملة لإعادة بناء التطبيق ليكون **قائمة تفقد وإنجاز مباشرة (Direct Topic Checklist)** مأخوذة حرفياً من دليل كليتها الموضح في الصورة، مع إرسال إشعارات تذكيرية دورية كل بضع ساعات، وإلغاء أي ذكاء اصطناعي تماماً.

---

## ملخص القرارات المؤكدة من المستخدم (Confirmed Decisions)

> [!IMPORTANT]
> 1. **إلغاء نظام البطاقات القديم ونظام أرقام المحاضرات:** استبداله بقائمة فصول وموضوعات حقيقية مأخوذة نصاً من صورة "دليلك التفصيلي لكل مادة في كليتك".
> 2. **نظام الـ Check المباشر:** إمكانية وضع علامة صح (Check) مباشرة على كل فصل أو موضوع تم إنجازه، مع عرض فوري وواضح لما تم إنجازه وما لم يُنجز بعد.
> 3. **إشعارات تذكيرية دورية:** نظام تنبيهات يرسل إشعاراً كل بضع ساعات ليسألها بلطف: *"هل ذاكرتِ أي حاجة من دول النهاردة؟"* لتشجيعها ومتابعة دراستها.
> 4. **إزالة الذكاء الاصطناعي (AI) بالكامل:** لا توجد أي أدوات أو شاشات AI.

---

## 2. واجهة المستخدم وتجربة الاستخدام (Checklist UI Flow)

```
┌────────────────────────────────────────────────────────┐
│     دليلك التفصيلي لكل مادة في كليتك (Checklist)        │
│    "خطوة بخطوة نحو حلمك • التنظيم هو نصف النجاح"      │
├────────────────────────────────────────────────────────┤
│  مؤشر الإنجاز الكلي: [ 18 / 52 موضوعاً تم إنجازه - 35% ]│
├────────────────────────────────────────────────────────┤
│  فلترة سريعة: [ كل المواد ] [ المتبقي ] [ المكتمل ]     │
├────────────────────────────────────────────────────────┤
│  ▼ كيمياء فيزيائية (CHM 111) [نظري وعملي]              │
│    ☑ مبادئ الديناميكا الحرارية وقوانينها (منجز اليوم) │
│    ☑ الاتزان الكيميائي ومفهوم ثابت الاتزان           │
│    ☐ سرعة التفاعلات الكيميائية وآلياتها               │
│    ☐ الخواص الفيزيائية للمحاليل والإلكتروليتات        │
│    ...                                                 │
├────────────────────────────────────────────────────────┤
│  ▼ رياضيات عامة (1) (MAS 111)                         │
│    ☑ الأسس والجذور واللوغاريتمات                     │
│    ☐ المعادلات والمتباينات                            │
│    ...                                                 │
└────────────────────────────────────────────────────────┘
```

* **طريقة العرض:** قائمة تفقد مرنة (Interactive Accordion / Sectioned Checklist):
  * كل مادة تمثل قسماً مميزاً بلونها وتفاصيلها من الصورة.
  * كل موضوع يحتوي على مربع اختيار (`Checkbox`) بنقرة واحدة، يتحول فوراً إلى علامة صح مع تغيير لون الخط وخلفية العنصر لتشعر بالإنجاز.
  * فلتر سريع: لعرض "المتبقي فقط" لتركز عليه، أو "المكتمل" لتفرح بإنجازها، أو "الكل".
  * شريط علوي يوضح عدد الموضوعات المنجزة والنسبة المئوية الإجمالية.

## 3. نظام الإشعارات والتذكير الدوري (Periodic Notifications)

* استخدام `NotificationManager` المدمج في نظام أندرويد لإنشاء قناة إشعارات خاصة باسم **"تذكير نبتة للمذاكرة"**.
* جدولة التذكير عبر `AlarmManager` / مؤقت دوري يعمل في الخلفية كل بضع ساعات (مثلاً كل 3 إلى 4 ساعات).
* نص الإشعار لطيف ومحفز:
  > **نبتة رفيقة دراستكِ**
  > *"هل ذاكرتِ أي حاجة من موضوعات كليتك النهاردة؟ ادخلي حطي صح على اللي خلصتيه"*
* زر اختباري في الواجهة "إرسال إشعار تجريبي الآن" لتمكينك من رؤية شكل التنبيه فوراً.

## 4. الخطوات التنفيذية (Implementation Steps)

1. **تحديث قاعدة البيانات (Room Database):**
   * إدخال الـ 52 موضوعاً وفصلاً الحقيقية المستخرجة نصاً من صورة البوستر بدلاً من المحاضرات الرقمية.
2. **إزالة ملفات الذكاء الاصطناعي القديمة:**
   * حذف `StudyNlpParser.kt` وأي دوال متعلقة بالـ AI أو معالجة النصوص.
3. **بناء شاشة الـ Checklist الرئيسية:**
   * واجهة مخصصة لعرض المواد وفصولها كقوائم فحص أنيقة وسريعة.
4. **تفعيل إذن ونظام الإشعارات (Android Notifications):**
   * إضافة `POST_NOTIFICATIONS` في `AndroidManifest.xml`.
   * إنشاء خدمة/مستقبل الإشعارات وتفعيل التنبيه الدوري كل بضع ساعات.
5. **التحقق والاختبار:**
   * التأكد من حفظ حالة كل عنصر في قاعدة البيانات واستمرارها، واختبار عمل الإشعار والتجميع بنجاح.
